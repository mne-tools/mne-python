The ``jupyterlite_notebook`` 3D backend was renamed ``notebook_js`` (the old name still works with a warning) and now offers the same ipywidgets GUI as the ``notebook`` backend, so :class:`mne.viz.Brain` can be given a time viewer in the browser with ``time_viewer=True``, and the ``notebook`` backend uses trame-pyvista's application (server rendering streamed by trame-rca, with a switch to VTK in WebAssembly) when available and renders on the main thread under JupyterLab's kernel subshells, by `Eric Larson`_.
