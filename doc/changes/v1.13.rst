API changes by deprecation
--------------------------

- Rename ``standard_1005`` and ``standard_1020`` montages to ``colin27_1005`` and ``colin27_1020``, respectively. If you used ``standard_1005`` or ``standard_1020``, either switch to the new names ``colin27_1005`` and ``colin27_1020`` or use the new spherical montages ``spherical_1005``, ``spherical_1010``, or ``spherical_1020``, which provide idealized template locations on a sphere (useful for plotting). By `Clemens Brunner`_. (`#13903 <https://github.com/mne-tools/mne-python/pull/13903>`__)
- In :meth:`mne.Evoked.animate_topomap` the ``vmin`` and ``vmax`` keyword arguments have been deprecated in favor of ``vlim`` and will be removed in MNE 1.14, by `Eric Larson`_. (`#13905 <https://github.com/mne-tools/mne-python/pull/13905>`__)
- In :func:`mne.viz.iter_topography`, the ``on_pick`` callable for sub-figures now has a new parameter ``orig_fig`` that refers to the main figure. To preserve backward compatibility, it is made optional. By `Lifeng Qiu Lin`_. (`#13968 <https://github.com/mne-tools/mne-python/pull/13968>`__)
- The ``block`` parameter of :meth:`mne.time_frequency.Spectrum.plot_topo`, the legacy ``plot_psd_topo`` methods, and ``mne.viz.plot_raw_psd_topo`` is deprecated and will be removed in MNE 1.14; these plots now follow Matplotlib's blocking behavior, by `Clemens Brunner`_. (`#14098 <https://github.com/mne-tools/mne-python/pull/14098>`__)
- Deprecate the ``epochs`` parameter of :func:`mne.compute_covariance` in favor of ``inst``; it will be removed in MNE 1.14, by `Hamza Abdelhedi`_. (`#14129 <https://github.com/mne-tools/mne-python/pull/14129>`__)
- The ``matplotlib`` 3D backend for plotting source estimates (``backend="matplotlib"`` in :func:`mne.viz.plot_source_estimates`, along with the ``spacing`` argument that only affects it) has been deprecated and will be removed in MNE 1.14; use a proper 3D backend such as ``pyvistaqt`` instead, by `Eric Larson`_. (`#14160 <https://github.com/mne-tools/mne-python/pull/14160>`__)
- Add ``rng`` parameters to APIs that use randomness, while retaining keyword-only ``seed`` and ``random_state`` for compatibility (:gh:`9233` by `Bruno Aristimunha`_). (`#14199 <https://github.com/mne-tools/mne-python/pull/14199>`__)
