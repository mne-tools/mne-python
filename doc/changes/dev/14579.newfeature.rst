Raw data browsers (e.g., :meth:`mne.io.Raw.plot`) can now be kept in sync by linking them with :func:`mne.viz.ui_events.link`: linked browsers follow each other when scrolling or zooming in time, and mirror each other's annotation edits. This uses the new UI events :class:`mne.viz.ui_events.TimeWindowChange` and :class:`mne.viz.ui_events.AnnotationsChange`, and is supported by the matplotlib browser backend, by `Nikhil Sinha`_.
