:func:`mne.preprocessing.infomax` now reports the number of iterations it actually performed, and :class:`mne.preprocessing.ICA`'s ``n_iter_`` follows. Convergence was signalled by assigning ``step = max_iter`` to leave the training loop, so a converged fit returned the iteration budget rather than the work done — most visibly for ``fit_params={"extended": True}``, where ``n_iter_`` was ``max_iter`` for a fit that converged in far fewer steps. The unmixing matrices are unchanged, by `Aslan Satary Dizaji`_.
