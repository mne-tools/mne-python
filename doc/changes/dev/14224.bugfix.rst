Fix incorrect TFCE scores in :func:`mne.stats.permutation_cluster_test`, :func:`mne.stats.permutation_cluster_1samp_test`, and related functions when using 1D data or non-unit threshold steps. The cluster extent was always counted as 1 for 1D data, and the per-threshold height contribution did not match the reference integral from :footcite:`SmithNichols2009`, by `Antonio Elias`_.
